DevOps infinity loop, minimal

The classic eight-phase DevOps loop drawn as plainly as it can be drawn, plus a few labelling variants for teaching and demos.

CC BY 4.0 5 files 2026-08-31 Source repository

Five transparent PNGs at 1672 x 941. Nothing but the loop: no logos, no tool icons, no gradients, no drop shadows. They are meant to be dropped onto any background and relabelled without a fight.

The variants exist because the eight-phase loop has one genuinely ambiguous spot. The two crossing segments in the middle both belong to "plan", and different courses put the label in different places. Rather than argue, here is each reading as its own file. The modified set moves deploy and release around for teams whose release step comes after the deploy step.

Base set

  • Plan first

    The eight phases with the plan label on the segment that opens the development loop. Reads plan, code, build, test, release, deploy, operate, monitor.

Modified: deploy and release swapped

  • Plan first, deploy and release swapped

    Deploy moves onto the crossing segment and release opens the operations loop, so the order reads test, deploy, release, operate, monitor. For teams where deploying a build and releasing it to users are separate events in that order.
