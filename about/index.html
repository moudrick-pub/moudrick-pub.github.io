About

A small, permanent home for work that is meant to be reused.

This is where moudrick publishes creatives and other material that is meant to be reused: diagrams, illustrations, and occasional writing.

The site is deliberately small. Each work is a set of files with a licence, a canonical source repository, and a ready-made attribution line. There is no tracking, no analytics, no cookies, and nothing loaded from a third party.

Corrections and reuse questions are welcome as issues on the source repository linked from each work.
